# 📀 Discava! — Your Vinyl Digging Experience

[![Vanilla JS](https://img.shields.io/badge/Vanilla-JS-yellow?style=flat-square&logo=javascript)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
[![CSS3](https://img.shields.io/badge/CSS3-Modern-blue?style=flat-square&logo=css3)](https://developer.mozilla.org/en-US/docs/Web/CSS)
[![API](https://img.shields.io/badge/API-Discogs-orange?style=flat-square&logo=discogs)](https://www.discogs.com/developers)

**Discava!** is a premium web platform designed for vinyl collectors and music enthusiasts specializing in Soul, Funk, and Disco. It replicates the "crate digging" experience digitally, allowing users to discover rare gems, preview tracks, and curate their own collection.

---

## ✨ Key Features

- 🔍 **Advanced Crate Digging:** Filter through millions of 7" and 12" releases using the Discogs database.
- 🎧 **Interactive Previews:** Listen to tracks directly from the search results to "test the groove."
- 📋 **Custom Playlists:** Save your favorite discoveries and generate dynamic YouTube playlists.
- 📱 **Premium Responsive UI:** A dark-themed, glassmorphic interface optimized for all devices.
- 🚀 **SEO & LLM Ready:** Implemented with Schema.org structured data, semantic HTML5, and `llms.txt` for AI-agent readability.

---

## 🛠️ Technical Stack & Architecture

As a Front End developer, I focused on building a scalable and maintainable codebase without heavy frameworks, showcasing core web proficiency.

- **Architecture:** Custom **MVC (Model-View-Controller)** pattern implemented in Vanilla JavaScript for clean state management and separation of concerns.
- **Styling:** Modern **CSS3** system using Design Tokens (CSS Variables), Flexbox, Grid, and Backdrop filters for a premium aesthetic.
- **API Integration:** Asynchronous communication with the **Discogs REST API** using Fetch/Await.
- **Components:** Modular JS components for the search engine, pagination, and modal views.
- **Performance:** Optimized image delivery (WebP) and minimal dependency footprint for fast loading times.

## 🚀 Getting Started

### Prerequisites
- A modern web browser.
- A local server environment (like VS Code Live Server).

### Installation
1. Clone the repository: git clone https://github.com/your-username/discava.git

2. Open the project folder: cd discava

3. Launch with your preferred local server.

### 🧠 Dev Notes: Why Vanilla JS?
This project was intentionally built with Vanilla JavaScript to demonstrate a deep understanding of DOM manipulation, asynchronous logic, and architectural patterns that are often abstracted away by frameworks like React or Vue. It highlights my ability to build complex, high-performance UIs from scratch.
